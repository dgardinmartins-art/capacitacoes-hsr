# Capacitações HSR

Página do aplicativo de capacitações mensais do Hospital São Roque de Caiçara (Sociedade Hospitalar de Caiçara).

- `index.html` é o aplicativo inteiro: entrada por nome e PIN, cartões, perguntas, comprovante e painel da administração.
- Os dados (pessoas, cursos, respostas e registros de acesso) ficam em um banco separado e não fazem parte deste repositório.
- `.github/workflows/ping.yml` toca o banco algumas vezes por dia para ele não ser pausado por inatividade.

Este repositório não contém dados pessoais nem o conteúdo dos cursos.
